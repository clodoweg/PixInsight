# Veille du 4 novembre 2026 : PixInsight 1.9.6

Période : depuis la veille du 20 octobre 2026 (thème : PixInsight 1.9.6 et impact sur les icônes). Rien n'est appliqué aux icônes : propositions à choisir.

## Résumé

1. PixInsight 1.9.6 « Lockhart », build 1713 (Windows, macOS, Linux) : grosse version, installeur complet (pas une simple mise à jour).
2. Nouveautés majeures : résolution astrométrique en aveugle (ImageSolver 6.6.0, script BlindSolver, index Gaia DR3 locaux), solution astrométrique gardée après Crop / DynamicCrop, MGC amélioré, MultiscaleTGVDenoise, MLDenoise sur plus de cartes NVIDIA.
3. Tes modules restent installables : RC Astro (dépôt 1.9.5:1.9.99), GHS, NarrowbandNormalization, NBColourMapper, StarReduction, ScreenStars, SyntheticLuminance (1.9.x:1.9.99), SetiAstro (1.9.4:1.9.9), Toolbox (1.9.4:1.9.7), VeraLux, EZ (1.9.9).
4. Aucune icône n'est cassée d'après les notes ; le seul vrai risque : GC_Solver_auto et ImageSolver_Date incluent le code d'ImageSolver, qui passe en 6.6.0 (à tester au premier lancement).
5. Autre : SetiAstro retire BlindSolver2000 et Cosmic Clarity (31 octobre) : tu ne les utilises pas.

## Propositions

1. **Tester Solver_auto en 1.9.6 avant tout traitement** (intérêt fort, coût 5 min) : lancer R_C_Preparation_rapide sur un objet déjà traité ; si erreur dans ImageSolver, je corrige GC_Solver_auto / ImageSolver_Date (code d'ImageSolver 6.6.0 à lire sur ton PC). Touche LRGB et LHaRGB si une correction est nécessaire (script partagé) : je te demanderai avant.
2. **Installer l'index Gaia DR3 standard (1,8 Go)** et le choisir dans Preferences du process Gaia (intérêt fort, gratuit) : ImageSolver se débrouille seul si l'en-tête n'a pas de coordonnées. L'index g19 (11 Go) est inutile pour ton champ.
3. **Ajouter `blindSolver` en Automatic dans l'icône Solver_auto** (intérêt moyen) : seulement si le paramètre n'est pas pris par défaut ; à décider après le test 1 (nom exact du paramètre à lire dans l'icône ImageSolver de la 1.9.6). Touche les 5 workflows, donc LRGB et LHaRGB : demande obligatoire.
4. **Option MLDenoise à comparer à NXT_final** (intérêt faible à moyen, gratuit) : en option P6 d'un workflow narrowband d'abord.
5. **Ne rien changer à MGC** pour l'instant (garder scaleFactor 1,00) ; tester une fois « Automatic scale factors » à la main sur une image avec gradient fort.
6. **Garder la 1.9.5 sur le Mac tant que le PC n'est pas validé**, ou passer les deux en 1.9.6 ensemble (XISF révision 2).

## Complément du 5 novembre 2026 (notes de version lues en entier)

- **PixelMath : division par zéro corrigée** (avant : plus grand nombre positif ; nouveau résultat non précisé). Seule formule touchée : Etoiles_reduites (Blanshan, `~mtf(~S,$T)` = 0 là où l'image sans étoiles vaut 1). À tester sur une image avec un cœur saturé ; si des pixels noirs ou faux apparaissent, protéger la division (non vérifié). Option seulement, 5 workflows, donc LRGB et LHaRGB : demande avant de toucher.
- **PJSR : `//` ou `/*` dans un gabarit entre backticks = erreur** : aucun de tes scripts n'utilise de backticks (vérifié).
- **Script lancé par un process qu'un autre script a lancé : ses propres paramètres** : Lineaire_auto lance des icônes par `ProcessInstance.fromIcon` ; changement plutôt favorable, à observer au premier essai.
- **ImageSolver** : corrigé l'échec sur une image sans date en mode non interactif avec base Gaia locale (ImageSolver_Date ajoute déjà une date) ; nouveau paramètre de dossier de sortie.
- **ImageIntegration, ChannelCombination, LRGBCombination** : température du capteur écrite en moyenne robuste (sans effet sur l'image).
- **XISF** : coefficients de luminance des espaces RGB toujours tirés des chromaticités (D50) ; un réglage RGBWorkingSpace personnalisé serait remplacé avec un avertissement (tu n'en as pas).
- **Modules PNG, WEBP, JPEGXL** : à installer une fois (Process › Modules › Install Modules) s'ils manquent.
- **Windows 11** : ajouter des exclusions xisf, xpsm, xdrz, xnml dans Sécurité Windows si les XISF sont signalés.
- **MLDenoise** : fuite de mémoire GPU corrigée (retour forcé au CPU sur les cartes de 4 à 8 Go).
- **SPFC, SPCC, PCC** : corrigé l'échec quand l'exécution des scripts non signés est désactivée.

## Hors sujet pour toi

- AstrometricRegistration, FeatureRegistration, mosaïques MARS : pas de mosaïques.
- ImageAnalysis, WBPP / FBPP 3.2, ImageIntegration Biweight : masters déjà empilés.
- AperturePhotometry 2.2, PhotometricAnalysis (AAVSO), FindingChart : photométrie, pas d'imagerie.
- Lecture des .fz (FITSC), SER : planétaire et formats que tu n'utilises pas.
